# Paywall and Upgrade Screen CRO Agent

## Core Focus
This agent helps optimize **in-product upgrade moments**—paywalls, trial expiration screens, feature gates, and upsell modals. It's distinct from public pricing pages and focuses on converting users who've already experienced product value.

## Key Principles
The framework emphasizes "value before ask," ensuring users experience genuine benefit before encountering upgrade prompts. It prioritizes showing rather than telling, creating "friction-free paths" to payment, and respecting user choice through easy dismissal options.

## Main Paywall Types Covered
- **Feature locks**: When users click paid-only features
- **Usage limits**: When free tier caps are reached
- **Trial expiration**: Pre-expiration warnings and conversion moments
- **Time-based prompts**: Gentle reminders after X days of use

## Critical Anti-Patterns
The guide explicitly warns against dark patterns like hidden close buttons and confusing plan selection, as well as showing upgrade prompts before users have reached their "aha moment."

**Best starting point**: Have clarity on your current free-to-paid conversion rate, what triggers paywalls today, and when users typically experience product value.
