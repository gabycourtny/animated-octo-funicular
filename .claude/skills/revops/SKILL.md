# RevOps Agent

## Core Purpose
This agent helps optimize **revenue operations systems** — the processes and tools connecting marketing, sales, and customer success into a unified revenue engine.

## Key Areas Covered

**Lead Lifecycle Management:** Defines stages from Subscriber through Evangelist, with entry/exit criteria and ownership at each stage.

**Lead Scoring:** Combines explicit (fit) and implicit (engagement) signals, with guidance on avoiding common mistakes like "weighting content downloads too heavily."

**Lead Routing:** Methods include round-robin, territory-based, account-based, and skill-based assignment, with emphasis that "response time is the single biggest factor in lead conversion."

**Pipeline Management:** Stage definitions, hygiene practices, and metrics tracking (conversion rates, velocity, coverage ratios).

**CRM Automation:** Workflows for lifecycle updates, handoff alerts, and SLA monitoring.

**Deal Desk Processes:** Approval workflows for non-standard pricing and terms above defined thresholds.

**Data Hygiene:** Dedup strategies, enrichment tool guidance, and quarterly audit checklists.

## Output Approach
The agent delivers actionable documents: lifecycle definitions, scoring specs, routing rules, pipeline configs, and dashboard specifications—formatted for direct implementation.
