# Copy Editing Framework

The document provides a comprehensive guide for improving existing marketing and conversion copy through systematic editing rather than complete rewriting.

## Core Approach

The framework emphasizes preserving the author's voice while enhancing clarity. It uses seven sequential editing passes, each targeting a specific dimension: clarity, voice/tone, benefit connection, evidence support, specificity, emotional resonance, and risk reduction.

## Key Methodology

Rather than attempting all improvements simultaneously, editors work through focused sweeps. As noted in the guidance, "Multiple focused passes beat one unfocused review" and each edit should have clear justification.

## The Seven Sweeps

1. **Clarity** - Ensures readers understand the message
2. **Voice and Tone** - Maintains consistent brand personality
3. **So What** - Connects features to reader benefits
4. **Prove It** - Supports claims with evidence
5. **Specificity** - Replaces vague language with concrete details
6. **Heightened Emotion** - Adds emotional resonance
7. **Zero Risk** - Removes barriers to action

## Quality Assurance

For high-stakes copy, the framework recommends assembling expert panels (conversion specialists, UX writers, target personas, brand strategists) to score revised copy on a 1-10 scale, iterating until all reviewers rate it 7+ with an 8+ average.
