# Image Agent - Complete Documentation

## Core Sections

**Image Generation Models:** Comparison of Gemini, Flux, Ideogram, GPT Image, Midjourney, and Stable Diffusion with decision trees for selecting the right tool.

**Design Tools:** Canva and Figma approaches for templated, brand-consistent work.

**Marketing Workflows:** Specific guidance for blog heroes, social graphics, product mockups, profile banners, and brand assets with platform-specific dimensions.

**Optimization:** Format recommendations (WebP, AVIF, JPEG, PNG, SVG) with compression commands and "lazy load below-the-fold images" practices.

**OG Images:** Meta tag requirements and dynamic generation approaches using Vercel OG, Satori, and Cloudinary.

## Key Takeaway

The guide emphasizes matching tools to tasks: "AI generation for unique visuals, design tools for templates, real screenshots for product UI—never AI-hallucinated interfaces."

Common pitfalls include skipping optimization, using wrong aspect ratios, and generating text-heavy images without Ideogram.
