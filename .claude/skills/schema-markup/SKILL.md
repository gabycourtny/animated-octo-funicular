# Schema Markup Guide

## What This Covers

This resource helps implement structured data for search engines. It applies when you need to "add, fix, or optimize schema markup" or want "rich snippets" and "Google rich results."

## Key Approach

The guidance emphasizes **accuracy first**—markup must genuinely represent your content. Use JSON-LD format, validate with Google's Rich Results Test, and ensure compliance with search engine guidelines.

## Common Schema Types

The most frequent implementations include:
- **Organization** - Company homepages
- **Article** - Blog posts with metadata
- **Product** - E-commerce pages with pricing
- **FAQPage** - Question-and-answer content
- **BreadcrumbList** - Navigation hierarchies
- **LocalBusiness** - Location-based services

## Implementation Path

Your approach depends on your tech stack:
- Static sites: Add JSON-LD directly to templates
- Dynamic frameworks (React/Next.js): Render server-side for SEO
- CMS platforms: Use plugins or theme modifications

## Next Steps

To get started, clarify: your page type, desired rich results, available data, existing schema, and technical platform.
