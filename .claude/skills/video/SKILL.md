# Video Production Guide

## Core Approaches

The guide identifies four main production methods:

1. **Programmatic video** — Use Hyperframes (HTML/CSS-based) or Remotion (React) to generate templated, data-driven videos at scale
2. **AI generation** — Models like Veo, Runway, and Kling create original footage from text prompts
3. **AI avatars** — HeyGen and Synthesia produce talking-head videos without filming
4. **Repurposing** — Tools like Descript and Opus Clip transform long-form content into social clips

## Tool Selection

The document recommends Hyperframes for agent compatibility because "plain HTML/CSS means any coding agent can generate frames without learning a framework." For avatars, HeyGen is highlighted as having official MCP server integration, enabling direct agent control.

## Critical Best Practices

- AI models "can't reliably render readable text" — avoid text-heavy AI-generated footage
- Captions are essential (85% of social video watched muted)
- Aspect ratios vary by platform: 9:16 for social, 16:9 for YouTube

## Workflow Integration

An "agent-native pipeline" combines these tools sequentially—script generation → templated video creation → B-roll generation → final assembly—requiring no manual editing.
